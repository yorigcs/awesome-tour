# @awesome-tour/react

## 0.1.0

Initial release: unstyled, accessible compound components (`Tour.*`, `Hotspot.*`, `Checklist.*`), hooks, `TourProvider`, i18n through `messages`, keyboard navigation, overlay cutouts, a top-layer portal and view transitions. `@awesome-tour/react/surfaces` adds announcements, surveys (NPS/CSAT/CES) and a help launcher.
