The `@awesome-tour/*` packages are versioned together; the packages listed under each version link
to it on npm. From 0.1.1 on, every version is published from GitHub Actions with a provenance
attestation and gets a [GitHub release](https://github.com/yorigcs/awesome-tour/releases).
