## Installation

<Tabs syncKey="pkg">
  <TabItem label="pnpm">
    ```sh
    pnpm dlx shadcn@latest add @awesome-tour/tour-motion
    ```
  </TabItem>
  <TabItem label="npm">
    ```sh
    npx shadcn@latest add @awesome-tour/tour-motion
    ```
  </TabItem>
</Tabs>

Installs [`tour`](../tour/), `@awesome-tour/motion` and `motion`.

## Usage

```tsx
import { TourMotionPopover } from '@/components/awesome-tour/tour-motion';

<Tour.Root tour={tour}>
  <TourMotionPopover preset="slide" backdrop="overlay" />
</Tour.Root>
```

| Prop                | Type                                  | Default     |
| ------------------- | ------------------------------------- | ----------- |
| `backdrop`          | `'overlay' \| 'spotlight' \| 'none'`   | `'overlay'` |
| `preset`            | `'slide' \| 'scale' \| 'fade' \| 'pop'` | `'slide'`   |
| `animateStepChange` | `boolean`                             | `true`      |
| `progress` · `dots` · `skip` · `size` | as in [`TourPopover`](../tour/#usage) | |

Parts: `TourMotionOverlay`, `TourMotionSpotlight`, `TourMotionCard`. Reduced-motion users get instant
transitions.
