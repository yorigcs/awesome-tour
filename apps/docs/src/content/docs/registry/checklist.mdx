## Usage

```tsx
import { ChecklistPanel } from '@/components/awesome-tour/checklist';

<ChecklistPanel
  checklist={gettingStarted}
  title="Getting started"
  description="3 quick wins to get going"
/>
```

Item titles and descriptions are read from `meta.title` / `meta.description`; pass `renderItem` to
map them differently. Once dismissed, the panel becomes a "Show checklist" button.

Parts: `ChecklistCard`, `ChecklistHeader`, `ChecklistProgressBar`, `ChecklistItems`, `ChecklistRow`.
