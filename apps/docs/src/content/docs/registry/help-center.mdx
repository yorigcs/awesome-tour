Built on the [Help launcher primitives](../../guides/launcher/) and a headless feed:

```ts
import { createFeed, localStorageAdapter } from '@awesome-tour/react';

export const news = createFeed({
  id: 'whats-new',
  persistence: localStorageAdapter({ prefix: 'feed:' }),
  items: await fetchReleaseNotes(), // { id, title, description?, date, href?, tour? }[]
});

<HelpCenter feed={news} checklist={gettingStarted} tours={[…]} links={[…]} />;
```

`createFeed` keeps read/unread state (`unread`, `markRead(id)`, `markAllRead()`, newest first);
`useFeed(feed)` reads it in React. Items with a `tour` start it; items with an `href` link out.
