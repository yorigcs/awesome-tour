## Usage

```tsx
import { HotspotHint } from '@/components/awesome-tour/hotspot';

<HotspotHint target="#export" title="New: PDF export" side="bottom">
  Export any report as a PDF, ready to share.
</HotspotHint>
```

The beacon's pulse is disabled for users who prefer reduced motion. Parts: `HotspotBeacon`,
`HotspotCard`, `HotspotTitle`, `HotspotDescription`.
